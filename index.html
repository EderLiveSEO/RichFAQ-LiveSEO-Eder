🛠️ Guia de Classes (Estrutura HTML)

Use estas classes para criar seu CSS:

  • .faq-container: Container principal.
  • .faq-title: Título da seção (H2).
  • .faq-item: Cada item de pergunta/resposta (`<details>`).
  • .faq-question: A pergunta (`<summary>`).
  • .faq-answer: A resposta (dentro de uma `<div>`).
  • details[open]: Estilo quando a resposta está aberta.
