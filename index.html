Gerador de FAQ Universal

💡 Dica: Deixe uma linha em branco entre cada par de pergunta/resposta.

🛠️ Todas as Classes CSS Geradas

  • .faq-container: Div principal que envolve tudo
  • .faq-title: Tag <h2> do título da seção
  • .faq-item: Tag <details> de cada pergunta
  • .faq-question: Tag <summary> (Texto da dúvida)
  • .faq-answer: Div interna com a resposta
  • details[open]: Seletor para estado "aberto"
  • summary::-webkit-details-marker: Marcador padrão (oculto)
  • .seo-text-container: Container principal do box
  • .seo-toggle: Checkbox oculto (controla estado)
  • .seo-content: Área do texto (expande/contrai)
  • .seo-btn-label: O botão "Ler mais/menos" (Label)
  • .seo-content h2/h3: Títulos e Subtítulos
